# Layla — E-Commerce Website (Portfolio Project)

A responsive **front-end ecommerce demo** built using **HTML, CSS, and vanilla JavaScript**. It is suitable for learning and showing work on GitHub.

## Features
- Responsive home page and product catalog
- 12 sample products in 4 categories
- Search, categories, sorting, product detail popups
- Add to cart, change quantities, remove items
- Cart saves to **localStorage** in your browser
- Simple checkout form and demo order history stored locally
- No external JavaScript packages; Google Fonts may require internet access

## How to run
1. Extract the ZIP folder.
2. Open `index.html` in Chrome or another modern browser.
3. Try the **Shop** and **Cart** features.
4. To edit code, open the folder using VS Code.

## Publish on GitHub Pages
1. Create a new **public** GitHub repository, e.g. `layla-ecommerce`.
2. Upload the three files (`index.html`, `styles.css`, `script.js`) and this README to the repository's root — **not the ZIP**.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then **Save**.
5. When deployment is complete, visit `https://YOUR-USERNAME.github.io/layla-ecommerce/`.

## Change the website
- **Name/brand**: change `Layla` and `novacart` in `index.html`.
- **Products/prices**: edit the `products` array at the top of `script.js`.
- **Colors**: edit the variables at the top of `styles.css`.
- **Your personal details**: add your name and portfolio link to this README or create a footer link.

## Important: demo, not a live store
This is a **front-end demonstration**, not a production-ready full-stack ecommerce service.
- Products are fictional examples, using emoji illustrations (not product photos).
- No database, authentication, backend API, admin dashboard, or payment processing.
- The checkout does **not charge money**, submit orders to a server, or arrange shipping.
- Local browser storage is **not** secure order storage. Do **not** type real card details or sensitive personal information into demo forms.
- For a real store, learn Node.js/Express, MongoDB, server-side validation, authentication, and a legitimate payment provider integration.
